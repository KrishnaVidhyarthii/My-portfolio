# My Personal Portfolio Website

## About the Project

This is a simple personal portfolio website created using HTML, CSS and JavaScript. It introduces me, my education, technical skills, projects, hobbies and achievements.

## Features

- **Home Section:** Displays my profile photo, name and introduction.
- **About Me:** Provides a short introduction about myself.
- **Education:** Shows my current education and course.
- **Skills:** Displays my programming skills with icons and progress bars.
- **Projects:** Highlights my current and future projects.
- **Hobbies and Interests:** Shows some of my personal interests with images.
- **Achievements:** Describes my learning progress and future goals.
- **Contact:** Displays my email address and phone number.
- **Dark / Light Mode:** Allows users to switch between dark and light themes.
- **Responsive Design:** Adjusts the website layout for smaller screens.
- **Navigation Bar:** Allows users to move between different sections of the website.

## Technologies Used

- **HTML:** Used to create the structure and content of the website.
- **CSS:** Used for styling, colors, layouts and responsive design.
- **JavaScript:** Used to implement the dark and light mode feature.
